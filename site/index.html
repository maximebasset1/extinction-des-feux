      Model vs reality

      For each qualifying, the model is replayed using only the races before it, as if it had run at the time. Each bar shows the chance it gave to the driver who took pole. The dashed line is a driver picked at random.

      2026 rounds 4 to 11 were used to choose the model, so it has an edge there. Forecasts actually published in advance are in the log below.

      Forecast log

      Each forecast is recorded before the session, never rewritten, then compared with the result.

      How it works

      Lap times since 2018, each driver's recent form, the car's pace, this weekend's practice sessions and the weather forecast feed a statistical model, retrained after every race. The calculation runs automatically on GitHub several times a day.

      Data: official timing via TracingInsights and FastF1, calendar Jolpica, weather Open-Meteo (CC BY 4.0). Source code. Unofficial student project, not affiliated with Formula 1, not a betting tool.
